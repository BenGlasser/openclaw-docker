  <name>Task 1: Align Dockerfile and entrypoint.sh with official docs</name>
  <files>Dockerfile, entrypoint.sh</files>
  <action>
**Dockerfile changes:**

1. Replace root user with node user (uid 1000) per official docs:
   - After the apt-get install block, add: `RUN mkdir -p /home/node/.openclaw /home/node/.openclaw/workspace && chown -R node:node /home/node/.openclaw`
   - Remove the line: `RUN mkdir -p /data/.openclaw && ln -s /data/.openclaw /root/.openclaw`
   - Change `VOLUME ["/root/.openclaw"]` to `VOLUME ["/home/node/.openclaw"]`
   - Add `USER node` before the CMD directive (after all root-requiring operations like apt-get, chown)
   - Remove the line: `COPY --chmod=755 connect-qr.sh .`

2. Fix CMD to use dist/index.js per official docs:
   - Change CMD from: `["node", "openclaw.mjs", "gateway", "--port", "18789", "--bind", "lan", "--allow-unconfigured"]`
   - To: `["node", "dist/index.js", "gateway", "--port", "18789", "--bind", "lan", "--allow-unconfigured"]`

3. Fix health check to use /healthz endpoint per official docs:
   - Change HEALTHCHECK from: `CMD node /healthcheck.js`
   - To: `CMD curl -f http://localhost:18789/healthz || exit 1`
   - Remove the line: `COPY healthcheck.js /healthcheck.js`
   - (curl is already installed in the apt-get block)

4. Remove EXPOSE 3001 and EXPOSE 3334 — only 18789 is needed per official docs.

5. Bump OPENCLAW_DOCKER_VERSION to "0.4.0".

**entrypoint.sh changes:**

1. Remove the two stale lines:
   - `./connect-qr.sh || true`
   - `apt install go || true`

2. Change `mkdir -p /data/.openclaw` to `mkdir -p /home/node/.openclaw` to match new volume path.

3. Update the "Data directory" log line to say `/home/node/.openclaw`.

Keep: token generation logic, dumb-init entrypoint pattern, exec "$@".
