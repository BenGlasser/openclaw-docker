<task type="auto">
  <name>Task 1: Test persistence and permissions</name>
  <files></files>
  <action>
Run a comprehensive persistence test sequence:

1. Build image (if not already built): `docker build -t openclaw-test .`
2. Create temp directory for volume: `mkdir -p /tmp/openclaw-persist-test`
3. Start container with volume mount:
   `docker run -d --name openclaw-persist -p 18789:18789 -v /tmp/openclaw-persist-test:/home/node/.openclaw openclaw-test`
4. Wait for container to start (check logs with `docker logs -f openclaw-persist` for up to 90 seconds)
5. Verify Control UI responds: `curl -s -o /dev/null -w "%{http_code}" http://localhost:18789/`
6. Check container user: `docker exec openclaw-persist whoami` (expect: node)
7. Check PID 1: `docker exec openclaw-persist ps aux | head -5` (expect: dumb-init as PID 1)
8. Create a marker file to test persistence: `docker exec openclaw-persist touch /home/node/.openclaw/test-marker`
9. Check volume on host: `ls -la /tmp/openclaw-persist-test/` (should show files with correct ownership)

Now test restart persistence:
10. Stop container: `docker stop openclaw-persist` — TIME THIS. Must complete in <10 seconds (graceful shutdown via dumb-init)
11. Check marker still exists on host: `ls /tmp/openclaw-persist-test/test-marker`
12. Restart: `docker start openclaw-persist`
13. Wait for startup, then verify marker exists inside container: `docker exec openclaw-persist ls /home/node/.openclaw/test-marker`
14. Verify Control UI still responds after restart: `curl -s -o /dev/null -w "%{http_code}" http://localhost:18789/`

Record results of each step. If any step fails, document the failure and attempt to diagnose.

Clean up: `docker rm -f openclaw-persist`
  </action>
  <verify>
    All 14 steps complete successfully:
    - Container runs as node user
    - dumb-init is PID 1
    - Control UI responds with 2xx/3xx
    - Volume contains files on host
    - Container stops in under 10 seconds
    - Marker file persists across restart
    - Control UI responds after restart
  </verify>
  <done>Container passes all persistence, permission, and restart tests. Data survives container stop/start cycle. Graceful shutdown confirmed.</done>

Test the Docker health check transitions:

   `docker run -d --name openclaw-health -p 18790:18789 -v /tmp/openclaw-health-test:/home/node/.openclaw openclaw-test`
2. Immediately check health (should be "starting"):
   `docker inspect --format='{{.State.Health.Status}}' openclaw-health`
3. Wait 30 seconds, check again — may still be starting (start-period is 60s)
4. Wait until 90 seconds total, check health — should be "healthy":
   `docker inspect --format='{{.State.Health.Status}}' openclaw-health`

   `docker inspect --format='{{json .State.Health}}' openclaw-health | python3 -m json.tool`
6. Verify health check is using node (not curl):
   `docker inspect --format='{{json .Config.Healthcheck}}' openclaw-health`

Clean up: `docker rm -f openclaw-health && rm -rf /tmp/openclaw-health-test /tmp/openclaw-persist-test`
  </action>
