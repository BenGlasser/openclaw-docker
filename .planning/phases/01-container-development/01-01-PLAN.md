Create entrypoint.sh (bash script):
```bash
#!/bin/bash
set -e

# Fix ownership of persistent volume if it exists
# This handles the case where host creates the directory with different UID
# The chown runs as the current user — if running as node, this may fail
# on directories owned by root, which is expected and safe to ignore
if [ -d /home/node/.openclaw ]; then
  chown -R node:node /home/node/.openclaw 2>/dev/null || true
fi

# Create .openclaw directory if it doesn't exist
mkdir -p /home/node/.openclaw

# Log startup info
echo "OpenClaw Docker container starting..."
echo "User: $(whoami) ($(id -u):$(id -g))"
echo "Data directory: /home/node/.openclaw"

# Replace this shell with the main command
# Critical: exec ensures signals from dumb-init reach the node process
exec "$@"
```

NOTE on permissions: Since USER node is set in Dockerfile, the entrypoint runs as node. The chown will only work if the volume files are already owned by node or if somehow running with elevated permissions. The `|| true` ensures it doesn't block startup. For Unraid, the volume will typically be created by Docker with root ownership — this is a known limitation addressed in the CONTEXT.md "Claude's Discretion" section. If chown fails as node user, the app may still work if the directory was created with appropriate permissions. Consider: the Dockerfile creates /home/node/.openclaw as node user during build, so on first run with an empty volume mount, Docker preserves the container directory's permissions.

Create healthcheck.js:
```javascript
const http = require('http');

const options = {
  hostname: 'localhost',
  port: process.env.OPENCLAW_PORT || 18789,
  path: '/',
  method: 'GET',
  timeout: 2000
};

const request = http.request(options, (res) => {
  if (res.statusCode >= 200 && res.statusCode < 400) {
    process.exit(0);
  } else {
    process.exit(1);
  }
});

request.on('error', () => {
  process.exit(1);
});

request.on('timeout', () => {
  request.destroy();
  process.exit(1);
});

request.end();
```

Health check hits root path (/) since OpenClaw may not have a dedicated /health endpoint. Accepts 2xx and 3xx status codes. 2-second timeout. Uses Node.js http module (no curl dependency needed for health checks).
