<task type="auto">
  <name>Task 1: Create GitHub Actions Docker publish workflow</name>
  <files>.github/workflows/docker-publish.yml</files>
  <action>
Create `.github/workflows/docker-publish.yml` with the following configuration:

**Triggers:**
- `push` to `main` branch
- `push` of tags matching `v*.*.*`
- `pull_request` (build-only, no push)
- `workflow_dispatch` (manual trigger for debugging)

**Environment variable:**
- `REGISTRY_IMAGE: ${{ secrets.DOCKERHUB_USERNAME }}/openclaw`

**Job 1: `build`** (runs on `ubuntu-latest`)
- Permissions: `contents: read`, `packages: write`
- Steps:
  1. `docker/setup-qemu-action@v3` — enable ARM64 emulation
  2. `docker/setup-buildx-action@v3` — configure buildx builder
  3. `docker/login-action@v3` — authenticate with DockerHub (skip on pull_request: `if: github.event_name != 'pull_request'`)
     - username: `${{ secrets.DOCKERHUB_USERNAME }}`
     - password: `${{ secrets.DOCKERHUB_TOKEN }}`
  4. `docker/metadata-action@v5` (id: `meta`) — generate tags and labels
     - images: `${{ env.REGISTRY_IMAGE }}`
     - tags:
       ```
       type=edge,branch=main
       type=semver,pattern={{version}}
       type=semver,pattern={{major}}.{{minor}}
       type=semver,pattern={{major}},enable=${{ !startsWith(github.ref, 'refs/tags/v0.') }}
       ```
     - flavor: `latest=auto`
  5. `docker/build-push-action@v6` — build and push
     - platforms: `linux/amd64,linux/arm64`
     - push: `${{ github.event_name != 'pull_request' }}`
     - tags: `${{ steps.meta.outputs.tags }}`
     - labels: `${{ steps.meta.outputs.labels }}`
     - cache-from: `type=gha`
     - cache-to: `type=gha,mode=max`
     - provenance: `mode=max`
     - sbom: `true`

**Job 2: `sync-readme`** (runs on `ubuntu-latest`)
- needs: `build`
- Condition: `if: github.event_name != 'pull_request'`
- Steps:
  1. `actions/checkout@v4` — clone repo for README access
  2. `peter-evans/dockerhub-description@v4` — sync README to DockerHub
     - username: `${{ secrets.DOCKERHUB_USERNAME }}`
     - password: `${{ secrets.DOCKERHUB_TOKEN }}`
     - repository: `${{ secrets.DOCKERHUB_USERNAME }}/openclaw`
     - readme-filepath: `./README.md`

**Important:** Use the exact action versions specified (v3, v4, v5, v6). These are the current stable versions per the research document.

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Configure DockerHub and GitHub secrets</name>
  <action>User must configure external services that Claude cannot access.</action>
  <instructions>
Before the workflow can run, you need to set up:

**1. DockerHub Repository:**
- Go to https://hub.docker.com/
- Create a public repository named `openclaw`

**2. DockerHub Access Token:**
- Go to DockerHub -> Account Settings -> Security -> New Access Token
- Name: `github-actions` (or similar)
- Scope: Read & Write
- Copy the token (you won't see it again)

**3. GitHub Repository Secrets:**
- Go to your GitHub repo -> Settings -> Secrets and variables -> Actions
- Add **repository secret**: `DOCKERHUB_TOKEN` = the access token from step 2
- Add **repository variable** (not secret): `DOCKERHUB_USERNAME` = your DockerHub username

**4. Verify:** Push to main or manually trigger the workflow from GitHub Actions tab.
  </instructions>
