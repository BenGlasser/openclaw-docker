Replace the entire `.github/workflows/docker-publish.yml` with an enhanced workflow containing three jobs: `build-release`, `build-dev`, and `sync-readme`.

**Workflow-level configuration:**
- name: "Docker Build and Publish"
- triggers: push to branches [main], push tags ["v*.*.*"], pull_request, workflow_dispatch
- env: REGISTRY_IMAGE: ${{ vars.DOCKERHUB_USERNAME }}/openclaw

**Job 1: `build-release`**
- runs-on: ubuntu-latest
- condition: `if: startsWith(github.ref, 'refs/tags/')`
- permissions: contents: read, packages: write
- Steps:
  1. `actions/checkout@v4` with `fetch-depth: 0` (need all tags for sorting)
  2. "Resolve mutable tag targets" step (id: `mutable`):
     - `git fetch --tags --quiet` (ensure all tags present)
     - Compute LATEST_TAG: `git tag --sort=-v:refname | grep -E '^v[0-9]+\.[0-9]+\.[0-9]+$' | head -1`
     - Compute BETA_TAG: `git tag --sort=-v:refname | grep -E '^v[0-9]+\.[0-9]+\.[0-9]+-beta(\.[0-9]+)?$' | head -1`
     - CURRENT_REF: `${{ github.ref_name }}`
     - Write to GITHUB_OUTPUT: `latest_tag`, `beta_tag`, `is_latest_target` (true if CURRENT_REF == LATEST_TAG), `is_beta_target` (true if CURRENT_REF == BETA_TAG)
  3. `docker/setup-qemu-action@v3`
  4. `docker/setup-buildx-action@v3`
  5. `docker/login-action@v3` with username: `${{ vars.DOCKERHUB_USERNAME }}`, password: `${{ secrets.DOCKERHUB_TOKEN }}`
  6. `docker/metadata-action@v6` (id: `meta`) with:
     - images: `${{ env.REGISTRY_IMAGE }}`
     - flavor: `latest=false` (per D-04, explicit control over latest)
     - tags (multi-line):
       ```
       type=semver,pattern={{version}}
       type=semver,pattern={{major}}.{{minor}},enable=${{ !startsWith(github.ref, 'refs/tags/v0.') }}
       type=semver,pattern={{major}},enable=${{ !startsWith(github.ref, 'refs/tags/v0.') }}
       type=raw,value=latest,enable=${{ steps.mutable.outputs.is_latest_target }}
       type=raw,value=beta,enable=${{ steps.mutable.outputs.is_beta_target }}
       ```
  7. `docker/build-push-action@v7` (upgrade from v6) with:
     - platforms: linux/amd64,linux/arm64
     - push: true
     - tags: `${{ steps.meta.outputs.tags }}`
     - labels: `${{ steps.meta.outputs.labels }}`
     - cache-from: type=gha
     - cache-to: type=gha,mode=max
     - provenance: mode=max
     - sbom: true

**Job 2: `build-dev`**
- runs-on: ubuntu-latest
- condition: `if: github.ref == 'refs/heads/main' || startsWith(github.ref, 'refs/tags/')` (per D-03 and D-04: dev always rebuilt)
- Do NOT run on pull_request: add `&& github.event_name != 'pull_request'`
- permissions: contents: read, packages: write
- Steps:
  1. `actions/checkout@v4` with `ref: main` (ALWAYS build main HEAD for dev tag, per D-03)
  2. `docker/setup-qemu-action@v3`
  3. `docker/setup-buildx-action@v3`
  4. `docker/login-action@v3` with same credentials as build-release
  5. `docker/metadata-action@v6` (id: `meta`) with:
     - images: `${{ env.REGISTRY_IMAGE }}`
     - flavor: `latest=false`
     - tags: `type=raw,value=dev`
  6. `docker/build-push-action@v7` with same build config as build-release (platforms, cache, provenance, sbom)
     - push: true
     - tags: `${{ steps.meta.outputs.tags }}`
     - labels: `${{ steps.meta.outputs.labels }}`

**Job 3: `sync-readme`**
- runs-on: ubuntu-latest
- needs: [build-release, build-dev]
- Use `if: always() && github.event_name != 'pull_request' && (needs.build-release.result == 'success' || needs.build-release.result == 'skipped') && (needs.build-dev.result == 'success' || needs.build-dev.result == 'skipped')` so it runs when either build succeeds or is skipped (per D-08)
- Steps:
  1. `actions/checkout@v4`
  2. "Check if README exists" step (id: `readme-check`): same logic as current workflow
  3. `peter-evans/dockerhub-description@v5` (upgrade from v4) with:
     - username: `${{ vars.DOCKERHUB_USERNAME }}`
     - password: `${{ secrets.DOCKERHUB_PW }}`
     - repository: `${{ vars.DOCKERHUB_USERNAME }}/openclaw`
     - readme-filepath: ./README.md
     - condition: `if: steps.readme-check.outputs.exists == 'true'`

**Key changes from existing workflow (per decisions):**
- Remove `type=edge,branch=main` (replaced by `dev` tag per D-03; remove `edge` — Claude's discretion)
- Remove `type=raw,value=latest,enable={{is_default_branch}}` (replaced by mutable resolution per D-01)
- Upgrade metadata-action v5 to v6, build-push-action v6 to v7, dockerhub-description v4 to v5
- Add `flavor: latest=false` to disable automatic latest assignment
- Split single `build` job into `build-release` (tag-only) and `build-dev` (main+tag)
