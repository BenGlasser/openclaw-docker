Create a new file `.github/workflows/docker-backfill.yml` with the following structure:

**Workflow-level configuration:**
- name: "Docker Backfill"
- trigger: workflow_dispatch only
- inputs:
  - `mode`: type: choice, required: true, options: ["build-tag-and-update-mutable", "mutable-only"], default: "mutable-only", description: "Operation mode"
  - `git_tag`: type: string, required: false, description: "Git tag to build (e.g., v1.0.0) -- required for build-tag-and-update-mutable mode"
- env: REGISTRY_IMAGE: ${{ vars.DOCKERHUB_USERNAME }}/openclaw

**Job 1: `validate`**
- runs-on: ubuntu-latest
- outputs: mode, git_tag, latest_tag, beta_tag
- Steps:
  1. `actions/checkout@v4` with `fetch-depth: 0`
  2. "Validate inputs" step:
     - MODE="${{ github.event.inputs.mode }}"
     - TAG="${{ github.event.inputs.git_tag }}"
     - If MODE == "build-tag-and-update-mutable":
       - If TAG is empty: `echo "ERROR: git_tag input is required for build-tag-and-update-mutable mode"; exit 1`
       - Validate tag format: `echo "$TAG" | grep -qE '^v[0-9]+\.[0-9]+\.[0-9]+(-beta(\.[0-9]+)?)?$'` or exit 1 with "ERROR: git_tag must be semver format (v1.0.0 or v1.0.0-beta.1)"
       - Validate tag exists: `git fetch --tags && git tag -l | grep -qx "$TAG"` or exit 1 with "ERROR: Tag $TAG does not exist in the repository"
     - Write to GITHUB_OUTPUT: `mode=$MODE`, `git_tag=$TAG`
  3. "Resolve mutable tag targets" step (id: `mutable`):
     - `git fetch --tags --quiet`
     - Compute LATEST_TAG: `git tag --sort=-v:refname | grep -E '^v[0-9]+\.[0-9]+\.[0-9]+$' | head -1`
     - Compute BETA_TAG: `git tag --sort=-v:refname | grep -E '^v[0-9]+\.[0-9]+\.[0-9]+-beta(\.[0-9]+)?$' | head -1`
     - Write to GITHUB_OUTPUT: `latest_tag=$LATEST_TAG`, `beta_tag=$BETA_TAG`
     - Echo summary: "Resolved: latest=$LATEST_TAG, beta=$BETA_TAG"

**Job 2: `build-tag`**
- runs-on: ubuntu-latest
- needs: validate
- condition: `if: needs.validate.outputs.mode == 'build-tag-and-update-mutable'`
- Steps:
  1. `actions/checkout@v4` with `ref: ${{ needs.validate.outputs.git_tag }}`, `fetch-depth: 0`
  2. "Check if image already exists on DockerHub" step (id: `image-check`):
     - IMAGE="${{ vars.DOCKERHUB_USERNAME }}/openclaw"
     - TAG="${{ needs.validate.outputs.git_tag }}"
     - DOCKER_TAG="${TAG#v}" (strip leading v)
     - Get anonymous bearer token: `TOKEN=$(curl -fsSL "https://auth.docker.io/token?service=registry.docker.io&scope=repository:${IMAGE}:pull" | jq -r '.token')`
     - Check manifest: `HTTP_CODE=$(curl -o /dev/null -s -w "%{http_code}" -H "Authorization: Bearer $TOKEN" -H "Accept: application/vnd.docker.distribution.manifest.v2+json" "https://registry-1.docker.io/v2/${IMAGE}/manifests/${DOCKER_TAG}")`
     - If HTTP_CODE == "200": echo "WARNING: Image ${IMAGE}:${DOCKER_TAG} already exists -- skipping build" and set `image_exists=true` in GITHUB_OUTPUT
     - Else: set `image_exists=false`
  3. `docker/setup-qemu-action@v3` with `if: steps.image-check.outputs.image_exists != 'true'`
  4. `docker/setup-buildx-action@v3` with `if: steps.image-check.outputs.image_exists != 'true'`
  5. `docker/login-action@v3` with `if: steps.image-check.outputs.image_exists != 'true'`, username: `${{ vars.DOCKERHUB_USERNAME }}`, password: `${{ secrets.DOCKERHUB_TOKEN }}`
  6. "Resolve tag type" step (id: `tag-type`) with `if: steps.image-check.outputs.image_exists != 'true'`:
     - TAG="${{ needs.validate.outputs.git_tag }}"
     - LATEST_TAG="${{ needs.validate.outputs.latest_tag }}"
     - BETA_TAG="${{ needs.validate.outputs.beta_tag }}"
     - Set `is_latest_target=true` if TAG == LATEST_TAG, else false
     - Set `is_beta_target=true` if TAG == BETA_TAG, else false
     - Determine if tag is stable or beta for semver expansion:
       - If TAG matches `^v[0-9]+\.[0-9]+\.[0-9]+$`: set `is_stable=true`
       - Else: set `is_stable=false`
     - Write all to GITHUB_OUTPUT
  7. `docker/metadata-action@v6` (id: `meta`) with `if: steps.image-check.outputs.image_exists != 'true'`:
     - images: `${{ env.REGISTRY_IMAGE }}`
     - flavor: `latest=false`
     - tags:
       ```
       type=semver,pattern={{version}},value=${{ needs.validate.outputs.git_tag }}
       type=semver,pattern={{major}}.{{minor}},value=${{ needs.validate.outputs.git_tag }},enable=${{ steps.tag-type.outputs.is_stable == 'true' && !startsWith(needs.validate.outputs.git_tag, 'v0.') }}
       type=semver,pattern={{major}},value=${{ needs.validate.outputs.git_tag }},enable=${{ steps.tag-type.outputs.is_stable == 'true' && !startsWith(needs.validate.outputs.git_tag, 'v0.') }}
       type=raw,value=latest,enable=${{ steps.tag-type.outputs.is_latest_target }}
       type=raw,value=beta,enable=${{ steps.tag-type.outputs.is_beta_target }}
       ```
  8. `docker/build-push-action@v7` with `if: steps.image-check.outputs.image_exists != 'true'`:
     - platforms: linux/amd64,linux/arm64
     - push: true
     - tags: `${{ steps.meta.outputs.tags }}`
     - labels: `${{ steps.meta.outputs.labels }}`
     - cache-from: type=gha
     - cache-to: type=gha,mode=max
     - provenance: mode=max
     - sbom: true

**Job 3: `build-mutable`**
- runs-on: ubuntu-latest
- needs: [validate, build-tag]
- condition: `if: always() && needs.validate.result == 'success'` (runs in both modes -- after build-tag completes or is skipped)
- strategy: matrix with include:
  - `{ name: latest, ref: "${{ needs.validate.outputs.latest_tag }}", tag: latest, skip: "${{ needs.validate.outputs.latest_tag == '' }}" }`
  - `{ name: beta, ref: "${{ needs.validate.outputs.beta_tag }}", tag: beta, skip: "${{ needs.validate.outputs.beta_tag == '' }}" }`
  - `{ name: dev, ref: main, tag: dev, skip: "false" }`
- Steps (each matrix entry):
  1. Skip check: `if: matrix.skip != 'true'`
  2. `actions/checkout@v4` with `ref: ${{ matrix.ref }}`
  3. `docker/setup-qemu-action@v3`
  4. `docker/setup-buildx-action@v3`
  5. `docker/login-action@v3` with same credentials
  6. `docker/metadata-action@v6` (id: `meta`) with:
     - images: `${{ env.REGISTRY_IMAGE }}`
     - flavor: `latest=false`
     - tags: `type=raw,value=${{ matrix.tag }}`
  7. `docker/build-push-action@v7` with same build config (platforms, cache, provenance, sbom), push: true

**Important implementation notes:**
- The build-mutable job rebuilds all three mutable tags (latest, beta, dev) by checking out the correct commit for each. Per Pitfall 5 in RESEARCH.md, Docker cannot retag without re-pushing, so rebuilds are required.
- The matrix `skip` field handles the case where no stable or beta tags exist yet (empty string from git tag sorting).
- The build-tag job handles D-11 (skip existing images) via the DockerHub manifest check.
- All steps in build-tag that depend on the image not existing use `if: steps.image-check.outputs.image_exists != 'true'`.
