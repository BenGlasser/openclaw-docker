<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Verify Unraid installation flow</name>
  <what-built>Complete Unraid template with PUID/PGID support, XML template in GitHub repository</what-built>
  <how-to-verify>
On your Unraid server:

1. **Add template repository:**
   - Go to Docker tab in Unraid WebGUI
   - Scroll to "Template repositories" section at bottom
   - Add the GitHub repo URL (e.g., https://github.com/benglasser/openclaw.docker)
   - Click SAVE

2. **Install from template:**
   - Click "Add Container" in Docker tab
   - Select "openclaw" from the template dropdown
   - Verify these fields are populated:
     - Repository: benglasser/openclaw
     - WebUI port: 18789 (editable)
     - Appdata path: /mnt/user/appdata/openclaw/ (editable)
     - Gateway Token: empty, masked (optional)
     - ANTHROPIC_API_KEY: empty, masked (optional)
     - PUID/PGID: visible only in advanced view, defaults 99/100
   - Click CREATE

3. **Verify container starts:**
   - Container should show as "running" in Docker tab
   - Health check should go from "starting" to "healthy" within ~60 seconds
   - Check container logs for "OpenClaw Docker container starting..." and PUID/PGID values

4. **Test WebUI access:**
   - Click the WebUI icon/button for openclaw in Docker tab
   - OpenClaw Control UI should load in browser
   - Note the URL format (should be http://[server-ip]:18789)

5. **Test data persistence:**
   - Make any configuration change in the Control UI (or just let it start)
   - Stop the container from Docker tab
   - Check /mnt/user/appdata/openclaw/ has files
   - Start the container again
   - Verify the configuration is preserved

6. **Verify permissions:**
   - SSH into Unraid or use terminal
   - Run: `ls -la /mnt/user/appdata/openclaw/`
   - Files should be owned by nobody:users (99:100)

Report any issues encountered. Common things to check:
- If WebUI doesn't load, check container logs for errors
- If permission errors, check PUID/PGID are being applied (container logs show them)
- If template doesn't appear in dropdown, verify the repo URL is correct and publicly accessible
  </how-to-verify>
  <resume-signal>Type "approved" if all 6 checks pass, or describe any issues encountered</resume-signal>
